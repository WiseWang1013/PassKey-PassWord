# 🔐 PassKey 通行密钥｜多格式文件加密工具
基于 Python + Tkinter 开发的跨平台图形化加密工具，支持文本、代码、图片、压缩包、音视频等几乎所有文件格式加密，支持拖拽导入、进度可视化，各平台可本地自行打包对应程序。

**✅ 当前Windows最新版本：v1.1（UI美化版）**
**✅ 历史版本：v1.0（原始基础版）**
**🟡 Beta测试源码版：v1.1.1-beta-for‑Linux / v1.1.1‑beta‑for‑Mac**
**💡 版本说明：v1.1 仅优化界面，底层加密算法完全不变；v1.0 / v1.1 / Beta版加密文件双向完全互通！**

---

## ✨ 核心功能
- **文本加密解密**：支持手动输入任意文字、代码内容加密
- **全类型文件加密**：支持文本类、代码类、图片、文档、压缩包、音视频等数十种格式
- **拖拽快速导入**：支持直接拖拽文件进软件，无需手动选择
- **智能加密策略**：不同文件格式自动匹配专属加密算法，安全性更高
- **进度条可视化**：大文件加密解密实时进度显示
- **深色科技UI**：v1.1 全新美化界面、彩色功能按钮、自适应窗口
- **完整导出体系**：独立导出密文、密钥、解密文件
- **各平台本地打包**：用户可在本机打包对应平台可执行程序，无需系统Python环境

## 📂 项目文件说明
- `PassKey.py`：项目主程序完整源码
- `app.ico`：Windows软件自定义图标文件
- `build.bat`：Windows一键打包 EXE 脚本
- `PassKey.spec`：PyInstaller 打包配置文件
- `hook-tkinterdnd2.py`：拖拽功能专属打包依赖文件（解决打包失效问题）
- `v1.0/`：历史原版源码文件夹（保留初代版本）

- `v1.1.1-beta-for-Mac/` 📂 macOS专属Beta源码版本

📖 完整使用说明
运行 PassKey.py 启动软件，支持两种工作模式：
1. 文本模式（手动输入内容加密）
直接在文本框输入文字、代码、内容
点击加密，设置自定义通行口令
导出密文文件 + 密钥文件保存
2. 文件模式（任意文件加密）
点击导入文件 或 直接拖拽文件到窗口
设置通行口令开始加密
分别保存密文 txt、密钥 txt
✅ 解密必须三样齐全（缺一不可）
加密生成的 密文 txt
加密生成的 密钥 txt
你自己设置的 通行口令
⚠️ 重要安全提醒（必读）
通行口令一旦丢失、遗忘，文件永久无法解密，无任何找回方式！
本项目仅用于 Python 编程学习、开源练习
