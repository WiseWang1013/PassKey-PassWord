# 🔐 PassKey 通行密钥｜多格式文件加密工具
![PassKey主界面](./screenshots/main_ui.png)
基于Python+Tkinter构建的图形化加密GUI工具，支持文件拖拽、文本/二进制文件加解密，Windows可打包单文件EXE。

> ⚠️ **版本重大警告：V2.0 不兼容 v1.0 ~ v1.1.1‑beta 的旧密文、旧密钥！旧版本加密的文件无法使用V2.0解密。**

**✅ 当前Windows最新正式版本：v2.0（批量加密新版）**
**✅ 历史版本：v1.1（UI美化版）、v1.0（原始基础版）**
**🟡 Beta测试源码版：v1.1.1‑beta‑for‑Linux / v1.1.1‑beta‑for‑Mac**
**💡 版本互通说明：v1.0 / v1.1 / v1.1.1‑beta 之间加密文件双向互通；v2.0使用全新加密逻辑，与旧版本完全隔离。**

## ✨ 核心功能
### 🆕 v2.0 新增特性
- **批量加密解密**：一次性多选多个文件，全部文件使用同一套密钥
- **统一异或加密**：不再区分文件后缀专属加密策略，支持几乎全部Windows文件格式
- **大文件多文件进度显示**：加密解密实时展示子任务进度
- **无密码加密**：支持口令留空，不设置密码保护
- **加密模式选择**：随机安全密钥（推荐） / 固定测试密钥（仅调试使用）
- **纯白简约全新UI**：左侧操作面板，右侧预览区域
- **使用协议弹窗**：内置版权、免责、版本说明弹窗
- **批量导出解密文件**：自动保留原始文件名与后缀格式

### 旧版本已有功能（v1.x）
- **文本加密解密**：支持手动输入文字内容加密
- **全类型文件加密**：支持图片、文档、压缩包等二进制文件加解密
- **拖拽快速导入**：直接拖拽文件进程序，无需手动选择路径
- **完整导出体系**：独立导出密文、密钥、解密文件
- **各平台本地打包**：用户可在本机打包对应平台可执行程序

> 📌 v2.0本版仅维护Windows；Linux、macOS暂不更新新版本，可继续使用旧Beta源码。

## 📦 运行环境依赖
Python 3.8 及以上
```bash
pip install tkinterdnd2 pyinstaller
```
> Linux /macOS 平台请查看对应v1.1.1‑beta版本内 README 安装平台专属依赖，**v2.0暂不支持Linux/macOS**。

### 🔨 打包教程
#### Windows（打包独立 EXE，v2.0）
1. 安装全部依赖库
2. 直接双击运行 `build.bat`
3. 打包完成，程序输出在 `dist` 文件夹

✅ 打包成果：单文件 EXE、带自定义图标、拖拽功能正常可用

⚠️ Linux / macOS：**v2.0没有适配**；v1.1.1‑beta分支不能Windows交叉编译，请在对应系统内本地编译。

## 📖 v2.0完整使用说明
运行 `PassKey.py` 启动软件

**批量导入文件**
点击【多选待加密文件】，或者直接把文件拖拽进窗口左侧列表。

**批量加密**
1. 选择加密模式：`随机密钥(推荐)` / `固定测试密钥`
2. 点击【批量加密全部文件】，输入口令（可以直接确定，不设置密码）
3. 加密完成后，分别导出「密文包」和「统一密钥txt」，两个文件必须同时保存。

**批量解密**
1. 点击【批量解密(密文+密钥)】，依次选择v2生成的密文包txt、统一密钥txt
2. 输入加密时设置的口令（无密码直接确定）
3. 解密完成，点击【批量导出解密文件】，选择保存文件夹，文件会按原始名字、后缀输出。

> ✅ v2.0解密必备条件（缺一不可）
> - v2.0生成的**密文包txt**
> - v2.0生成的**统一密钥txt**
> - 加密时设置的通行口令
>
> ❗ 无法解密v1.x版本生成的密文密钥。

## ⚠️ 重要安全提醒（必读）
通行口令一旦丢失、遗忘，文件永久无法解密，没有找回手段！

本项目仅用于 Python 编程学习、开源练习。
- v2.0优先适配Windows平台；Linux、macOS仅可使用旧v1.1.1‑beta源码，没有v2版本。
- 禁止用来加密重要业务、机密资料，重要文件务必备份原始文件。
- 暂无安卓版本。
- 禁止利用本工具做恶意加密、锁机、勒索等一切违规违法行为。
